# Probes for quantitative and formal content

In quantitative subjects, understanding means connecting procedures to the principles behind them. Conceptual knowledge (why a procedure works, what the terms mean, how elements relate) and procedural knowledge (how to execute the steps) develop iteratively and support each other. A learner who can only execute the procedure has not understood it; a learner who only knows the idea but cannot use it has not either. Probe both and keep linking them.

Pick the probes that fit the concept. Do not run through the list mechanically; one well-chosen probe is worth more than five routine ones.

## Meaning of the components

- "What does this term (variable, parameter) represent in the real situation?"
- "Why does this term enter with a plus (minus, as a product, squared, in the denominator)?"
- "What unit does this have? Does the equation balance in units?"
- "What would it mean economically / physically if this term were zero?"

## Where the result comes from

- "Where does this formula come from? Which assumption or step produces it?" Prefer having the learner derive or reconstruct a result over having them state it.
- "Which step of the procedure corresponds to which idea?" Connect each computational step to its conceptual purpose.
- "Why is this the condition for an optimum (equilibrium, convergence)? What would be wrong if it did not hold?"

## Prediction before computation

- Before the learner calculates, ask for the direction and rough size of the effect: "If X increases, does Y go up or down, and roughly by how much? Why?" Then compute. A wrong prediction with a correct computation is a valuable signal that the procedure runs without understanding.
- Comparative statics: "What happens to the result if this parameter changes? Through which channel?"

## Limiting and special cases

- "What happens as this parameter goes to zero (to infinity, to one)? Does the result make sense there?"
- "Which special case reduces this model to one you already know?"
- "Is there a case where the formula gives an absurd result? What does that tell us about its assumptions?"

## Assumptions

- "Which assumptions does the model rely on? Which one matters most for the result?"
- "Drop assumption X. What changes, and why?"
- "In which real situation is this assumption clearly violated? Can the model still be used there?"

## Representations

- Ask the learner to switch representations: from equation to graph, from graph to verbal explanation, from verbal explanation to a numerical example. Understanding shows in the ability to translate; if the learner can only operate in one representation, probe the others.
- "Sketch (or describe) the graph. What does the slope mean? What does a shift of the curve mean?"

## Comparing methods and similar concepts

- Present two solution methods for the same problem, or a correct and a typical incorrect one, and ask which is right and why. Comparing solution methods is particularly effective in mathematics.
- "How does this concept differ from [similar concept]? When would you use which?"

## Transfer in quantitative subjects

A good quantitative transfer question keeps the mathematical structure but changes the context (the same optimization logic in a different market), or changes a condition so that the standard procedure no longer applies directly and the learner has to adapt it. Avoid transfer questions that are only the same exercise with different numbers; that tests the procedure, not the understanding.
